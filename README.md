# GitHub Explorer — удобный скачивальщик проектов

Одностраничный веб-инструмент для поиска и скачивания проектов с GitHub. Введите ник, ссылку на репозиторий или поисковый запрос — откроется страница с авторами и репозиториями, откуда в один клик можно скачать код или файлы релизов.

Никаких установок, регистраций и зависимостей: чистый HTML + CSS + JavaScript в одном файле. Работает прямо в браузере.

---

## Что умеет

- **Три режима поиска в одной строке**
  - `torvalds` — открывает профиль пользователя
  - `https://github.com/torvalds/linux` — открывает владельца с фильтром по репозиторию
  - `linux kernel` — открывает страницу результатов с авторами и репозиториями

- **Страница результатов** — сверху авторы, снизу репозитории. Если авторов нет, секция не показывается — сразу идут проекты.

- **Скачивание в один клик**
  - **Скачать код** — ZIP-архив ветки по умолчанию
  - **Файлы релизов** — список ассетов последнего релиза с размерами
  - **Все релизы** — переход на страницу релизов репозитория

- **Удобный просмотр профиля**
  - Аватар, имя, био, компания, локация, блог, подписчики
  - Статистика: проектов, звёзд, языков
  - Поиск по репозиториям, сортировка (обновление, дата, звёзды, алфавит)
  - Подсветка конкретного репозитория при переходе по `#user/repo`

- **Живые подсказки** при вводе — параллельно ищутся пользователи и репозитории, с аватарками и описаниями

- **Локализация** — русский и английский, автоопределение по языку браузера (`ru`, `uk`, `be` → русский, остальные → английский). Переключатель в шапке.

- **Тёмная и светлая темы** — автоматически по системным настройкам

- **Кеш API на 10 минут** — повторные заходы почти мгновенные, не тратят лимит GitHub

- **Персональный токен GitHub** (опционально) — поднимает лимит с 60 до 5000 запросов в час и открывает доступ к приватным репозиториям. Хранится только в браузере пользователя.

## Как пользоваться

1. Откройте страницу.
2. Введите в поиск одно из:
   - ник на GitHub (`torvalds`),
   - ссылку на репозиторий (`https://github.com/torvalds/linux`),
   - свободный запрос (`machine learning`, `python cli`).
3. Нажмите **Найти**.
4. На странице результатов:
   - **Авторы** — карточки пользователей с кнопкой «Профиль»
   - **Репозитории** — карточки с кнопками **Открыть**, **Скачать код**, **Файлы релизов**
5. Для скачивания нажмите соответствующую кнопку — файл начнёт загружаться сразу.

## Установка и размещение

### Локально

Скачайте `index.html` и откройте в браузере. Всё.

### На GitHub Pages

1. Создайте репозиторий, например `github-explorer`.
2. Положите `index.html` в корень.
3. В настройках репозитория → **Pages** → Source: `Deploy from a branch` → `main` / `root`.
4. Через минуту сайт будет доступен по адресу `https://ваш-ник.github.io/github-explorer/`.

### На своём хостинге

Загрузите `index.html` в любую папку — Apache, Nginx, Netlify, Vercel, Cloudflare Pages. Никаких серверных зависимостей.

## Лимиты GitHub API

Без токена — **60 запросов в час** на IP. Хватает на несколько поисков и просмотр профилей.

С персональным токеном — **5000 запросов в час**. Токен создаётся тут: <https://github.com/settings/tokens>. Достаточно прав `public_repo` (или вообще без прав, если нужны только публичные данные). Вставьте токен в разделе **«Диагностика и доступ к GitHub»** внизу страницы — он сохранится в `localStorage` браузера и будет подставляться в запросы.

> Токен никуда не отправляется, кроме `api.github.com`. Он не покидает ваш браузер.

## Технические детали

- Один HTML-файл, ноль зависимостей, ноль сборки.
- Роутинг на hash: `#login`, `#login/repo`, `#q=запрос`.
- Кеш API в `localStorage`, TTL 10 минут.
- Язык интерфейса и токен — тоже в `localStorage`.
- Все внешние ссылки открываются с `rel="noopener noreferrer"`.
- Поддержка `prefers-color-scheme` и `prefers-reduced-motion`.
- Адаптив до мобильных.
